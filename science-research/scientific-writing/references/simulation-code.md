# Simulation Code Requirements

This guide specifies the requirements for Python simulation code in wireless communications research papers, particularly for generating figures and results.

---

## Figure Output Format

### ⚠️ CRITICAL REQUIREMENT: EPS Format

All figures generated by Python simulation code **MUST** be saved in **EPS (Encapsulated PostScript)** format for insertion into LaTeX documents.

| Format | Allowed | Reason |
|--------|---------|--------|
| `.eps` | ✅ **REQUIRED** | Standard for academic LaTeX, vector quality |
| `.pdf` | ⚠️ Acceptable alternative | When EPS unavailable |
| `.png`, `.jpg` | ❌ **NOT RECOMMENDED** | Raster format, quality loss |

### Python Code Template (matplotlib)

When generating figures with Python, use the following code pattern:

```python
import matplotlib.pyplot as plt
import numpy as np

# Create your plot
fig, ax = plt.subplots(figsize=(6, 4))

# Plot your data
ax.plot(x, y, 'b-', linewidth=2, label='Proposed')
ax.plot(x, y_baseline, 'r--', linewidth=2, label='Baseline')

# Labels and title
ax.set_xlabel('X Label', fontsize=12)
ax.set_ylabel('Y Label', fontsize=12)
ax.set_title('Figure Title', fontsize=14)
ax.legend(fontsize=10)
ax.grid(True, linestyle=':', alpha=0.7)

# ⚠️ CRITICAL: Save as EPS format
plt.savefig('figure_name.eps', format='eps', bbox_inches='tight')
plt.close()
```

**Required parameters**:
- `format='eps'` - Explicitly set EPS format
- `bbox_inches='tight'` - Remove extra whitespace

**Recommended additional parameters**:
```python
plt.savefig('figure_name.eps',
            format='eps',
            bbox_inches='tight',
            dpi=300,           # High resolution
            transparent=False)  # White background (default)
```

### Multiple Subplots

For figures with multiple subplots:

```python
import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Plot on each subplot
axes[0, 0].plot(x1, y1)
axes[0, 1].plot(x2, y2)
axes[1, 0].plot(x3, y3)
axes[1, 1].plot(x4, y4)

# Add labels and titles
axes[0, 0].set_xlabel('X1')
axes[0, 0].set_ylabel('Y1')
axes[0, 0].set_title('Subplot 1')
# ... repeat for other subplots

plt.tight_layout()  # Prevent overlapping

# ⚠️ CRITICAL: Save as EPS format
plt.savefig('multi_subplot.eps', format='eps', bbox_inches='tight')
plt.close()
```

### Verification

After generating figures, verify the format:

```bash
# List all EPS files in current directory
ls -la *.eps

# Check file format
file figure_name.eps
# Expected output: figure_name.eps: EPS data
```

## Common Pitfalls

### ❌ Wrong: PNG format
```python
plt.savefig('figure.png')  # Wrong format!
```

### ❌ Wrong: Missing format parameter
```python
plt.savefig('figure.eps')  # May not produce correct EPS!
```

### ✅ Correct: Explicit EPS format
```python
plt.savefig('figure.eps', format='eps', bbox_inches='tight')
```

## Integration with LaTeX

After generating EPS figures, insert them into LaTeX:

```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.85\columnwidth]{figure_name.eps}
    \caption{Simulation results showing X versus Y.}
    \label{fig:results}
\end{figure}
```

Refer to the figure in text:
```latex
As shown in Fig.~\ref{fig:results}, the proposed method achieves...
```
