# RIS Code Integration Guide

This reference describes how to integrate the existing RIS simulation codebase when solving RIS-related research problems.

## When to Use This Reference

**Use this reference when**:
- The research problem involves Reconfigurable Intelligent Surfaces (RIS)
- The problem requires beam training, near-field communications, or channel modeling
- Experimental validation needs RIS system simulation

**Do NOT use this reference when**:
- The research problem is unrelated to RIS systems
- Working on other wireless communication technologies (NOMA, massive MIMO without RIS, etc.)

## Integration Example

### Complete Experiment Template

```python
"""
RIS Near-Field Beam Training Experiment
Generated by independent-scientific-research skill
"""

import sys
import os
import numpy as np
import matplotlib.pyplot as plt

# Add RIS code to path
sys.path.append('D:/workspace/git/ris/python')

# Import RIS modules
from src.config.array_config import UniformPlanarArrayConfig
from src.config.channel_config import NearFieldChannelConfig
from src.config.performance_config import PerformanceConfig
from src.core.implementations.uniform_arrays import UniformPlanarArray
from src.core.implementations.near_field_channel import NearFieldChannel
from src.core.implementations.performance_evaluation import PerformanceEvaluation
from src.visualization.array_visualizer import ArrayVisualizer

# Set random seed for reproducibility
np.random.seed(42)

# Experiment parameters
N_ris = 64  # Number of RIS elements
distance = 5  # Distance (m)
fc = 28e9  # Carrier frequency (Hz)

# Create configurations
ris_config = UniformPlanarArrayConfig(
    N_x=int(np.sqrt(N_ris)),
    N_y=int(np.sqrt(N_ris)),
    dx=0.5,
    dy=0.5,
    frequency=fc
)

channel_config = NearFieldChannelConfig(
    distance=distance,
    fc=fc
)

perf_config = PerformanceConfig(
    bandwidth=10e6,
    transmit_power_dbm=30,
    noise_figure_db=5
)

# Create objects
ris_array = UniformPlanarArray(ris_config)
channel = NearFieldChannel(channel_config)
evaluator = PerformanceEvaluation(perf_config)

# Run experiment
H = channel.compute_channel()
optimal_phase = ris_array.get_optimal_phase(H)
snr = evaluator.evaluate_snr(H, optimal_phase)

print(f"Optimal SNR: {snr:.2f} dB")

# Visualize
fig, ax = plt.subplots(figsize=(8, 6))
im = ax.imshow(np.abs(H), cmap='viridis')
ax.set_xlabel('RIS Element Index')
ax.set_ylabel('Receiver Element Index')
ax.set_title('Near-Field Channel Magnitude')
plt.colorbar(im, ax=ax, label='Magnitude')

# Save figure
script_dir = os.path.dirname(os.path.abspath(__file__))
output_dir = os.path.join(script_dir, 'docs', 'figures')
os.makedirs(output_dir, exist_ok=True)
save_path = os.path.join(output_dir, 'experiment_ris_channel.png')
plt.savefig(save_path, dpi=300, bbox_inches='tight')
plt.close(fig)

print(f"Figure saved: {save_path}")
```

## Code Principles

**Important conventions** from `D:\workspace\git\ris\python\docs\code-principle.md`:

1. **Absolute imports only**: Always use `from src.config.xxx import`
2. **Single data source**: All parameters from `config` objects
3. **Phase variable naming**:
   - `phase_vector` = complex values `e^(j*theta)`
   - `phase_angles` = real angles in radians
4. **Runtime parameter changes**: Use `update_config(**kwargs)`

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Module not found | Check `sys.path.append('D:/workspace/git/ris/python')` |
| Import errors | Use absolute imports from `src/` root |
| Phase calculation errors | Distinguish `phase_vector` (complex) vs `phase_angles` (real) |
| Visualization issues | Set matplotlib backend: `import matplotlib; matplotlib.use('Agg')` |
