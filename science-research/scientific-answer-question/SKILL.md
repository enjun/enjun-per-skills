# 概述
回答科学问题需要遵循客观、严谨的原则。论点需要基于可靠的证据和逻辑推理。如果是他人的内容，则必须引用参考文献，在引用时需要注明出处。

**重要提示**:
- **公式格式**: 输出内容中所有数学公式必须使用LaTeX格式（如 $E = mc^2$ 或 $$\int_0^\infty f(x)dx$$）
- **文献工具**: zotero-mcp工具可以直接使用，无需用户额外授权
- **输出要求**: 必须提供问题的具体答案，不能只返回分析框架

## 步骤

### 1. 问题分析与关键词提取
分析用户提出的问题，提取核心概念和关键词。确定需要查询的文献主题范围。

### 2. 文献查询
使用zotero-mcp工具查询相关文献：
- 使用 `mcp__zotero-mcp__search` 或 `mcp__zotero-mcp__zotero_semantic_search` 查询文献
- 使用 `mcp__zotero-mcp__zotero_get_item_metadata` 获取文献详细信息
- 对重要文献使用 `mcp__zotero-mcp__zotero_get_item_fulltext` 获取全文内容

查询策略：
1. 先使用语义搜索找到最相关的文献
2. 获取前5-10篇最相关文献的详细信息和摘要
3. 对于核心文献（星标注或高相关度），获取全文内容

### 3. 文献深度分析
阅读和分析查询到的文献，提取相关信息和证据：

**分析要点**：
- 文献的研究问题和主要贡献
- 关键方法、算法和理论框架
- 重要实验结果和性能数据
- 不同文献之间的联系和差异

**注意事项**：
- 避免引用错误或误导性的文献
- 对文献的观点需要批判性地采纳
- 提取具体的公式、数据、图表内容
- 所有数学公式必须转换为LaTeX格式

### 4. 综合与回答
根据多篇文献的分析结果，综合回答用户的问题，保存回答结果为markdown文件。

**回答结构**：
1. **直接回答**：先用1-3句话给出问题的核心答案
2. **详细解释**：展开说明关键概念、方法和机制
3. **文献支撑**：引用具体文献的内容和数据来支撑每个观点
4. **公式说明**：如需要，用LaTeX格式给出关键公式
5. **总结建议**：给出实施建议或未来方向

**输出要求**：
- 重点突出、表达简洁、逻辑清晰
- 所有引用必须标注文献来源（作者、年份、DOI）
- 数学公式使用LaTeX格式
- 必须给出问题的具体答案
