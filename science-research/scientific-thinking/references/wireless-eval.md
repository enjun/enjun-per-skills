# 无线通信与工程仿真研究评估清单

## 适用范围

本文件覆盖无线通信/信号处理/工程仿真类研究特有的评估点，适用于评估论文、审自己的稿、规划仿真与原型实验。RIS（可重构智能表面）、太赫兹、6G、大规模 MIMO、通感一体、ML for communications 等方向的研究者为主要读者。

**使用方式：** 配合 `critical-thinking.md` 使用——通用方法学问题（效度、偏倚、统计、谬误）走通用框架；通信研究特有的高频问题按本清单逐节检查。

---

## 1. 基线选择与公平性

对比实验是通信论文的核心证据，也是最容易出问题的地方。

### 1.1 基线是否充分
- 是否对比了 SOTA 方法？还是只对比了明显偏弱的经典方法？
- 基线是否覆盖不同技术路线（模型驱动 vs 数据驱动 vs 混合）？
- 近两年的强基线是否缺席？（所引基线是否停留在几年前的方法水平）
- 是否存在"稻草人基线"——实现粗糙、参数未调、刻意挑选的弱基线？

### 1.2 对比设置是否公平
- 信道模型/场景/拓扑是否与基线完全一致？
- **导频/训练/反馈开销是否计入并拉平？**（很多"增益"其实来自开销差异——自己方法用了更多导频，性能自然更高）
- 天线数、带宽、功率、编码调制方式等系统配置是否一致？
- 计算复杂度是否用同一口径计量（浮点运算数、时延、存储）？是否包含 FFT、矩阵求逆/分解、迭代求解等主导项？
- 自己的方法是否精心调参，而基线用默认参数陪跑？
- 随机性控制（种子、重复次数）是否对双方一致？
- 曲线上的对比点是否取在双方各自最优处，还是只在自己方法的最优点上比较？

### 1.3 消融是否充分
- 每个组件的贡献是否单独量化（逐一移除/替换）？
- 是否区分了"新机制本身的增益"与"额外计算/开销带来的增益"？
- 默认参数/超参的选择是否有敏感性分析支撑，还是拍脑袋定值？

## 2. 仿真设置严谨性

### 2.1 信道模型合理性
- 信道模型是否与场景匹配？（3GPP TR 38.901 系列、标准轨道/散射体模型、测量驱动模型、自设简化模型）
- 自设简化模型是否说明依据、并与标准模型对比验证？
- 是否过度理想化：完美 CSI、完美同步、理想硬件、忽略干扰？
- 理想化假设是否在系统模型中**显式声明**，而非藏在公式推导的默认记号里？

**RIS 类研究特有检查点：**
- 级联链路（BS-RIS-UE）是否正确建模？直射链路是否考虑？
- 无源波束赋形是否满足物理约束（单位模约束、离散相位移位器的比特数）？
- RIS 信道估计开销是否计入？估计误差下的鲁棒性是否评估？
- 近场/远场边界是否与阵列孔径和工作频率一致？

**太赫兹类研究特有检查点：**
- 分子吸收是否建模？频段选择与吸收窗口是否一致？
- 阻挡（blockage）敏感性是否讨论？LOS 依赖性如何处理？
- 波束训练/对准开销是否计入？
- 近场球面波前是否在相应距离内正确建模？

### 2.2 随机性控制
- 蒙特卡洛重复次数是否足够？**低 BER 需要足够错误事件**——宣称 BER 1e-5 至少需要 1e6~1e7 比特量级的仿真量
- 是否报告置信区间/误差棒，还是只给单条平滑曲线？
- 随机种子策略是否说明？固定种子是否被"挑过"（只留好看的运行）？

### 2.3 参数设置与扫描
- 参数取值是否与引用文献/标准一致？偏离是否说明？
- 关键参数（阵元数、子阵列规模、频段、带宽）是否有扫描曲线，还是只报单点？
- 扫描范围是否覆盖整个工作区间，还是只挑有利区间？
- 横轴变量（如 SNR）范围是否让所有方法的差异都可见，还是截取放大差异的区间？

### 2.4 可复现性
- 参数表是否完整到可复现？（缺一个信道相干时间/克隆因子/噪声口径就无法复现）
- 代码与数据是否公开？未公开时是否至少给足参数细节？
- 仿真工具与版本是否声明（MATLAB/Python/NS-3，库版本）？

## 3. 硬件损伤与场景真实性

### 3.1 硬件损伤建模
以下损伤是否考虑（至少声明未建模）：
- 相位噪声、本振漂移
- 幅相失衡（I/Q imbalance）
- 量化误差、ADC/DAC 有限分辨率
- 功放非线性、动态范围限制
- 阵元互耦、幅相误差、阵元失效
- RIS 相移网络的实际响应（离散相位、频率相关响应）

- 声称"硬件可行/低复杂度可实现"的研究，是否有损伤条件下的鲁棒性仿真或原型验证？

### 3.2 理想化假设的代价
- 每个理想化假设对结论的影响是否讨论？（去掉完美 CSI 后增益还剩多少？）
- 是否用"鲁棒性版本"（鲁棒波束赋形、估计误差模型）做过对照？

## 4. ML/AI 方法专项

通信 + ML 的论文有其特有的失效模式，单独核查。

### 4.1 数据与划分
- 训练/验证/测试划分是否按场景/快照/拓扑隔离？（相邻时隙快照高度相关，不隔离等于泄漏）
- 测试数据是否参与过任何超参选择或模型选择？
- 数据量、生成方式、分布是否声明？
- 输入归一化/统计量是否用了测试集信息？（常见泄漏点）

### 4.2 与模型驱动方法的公平对比
- 训练时间、训练数据需求、推理时延是否与基线一起报告？
- 部署侧开销是否讨论：换场景要不要重训？新配置（不同天线数）泛化代价多大？
- 混合方法是否与纯模型驱动、纯数据驱动双向对比？
- 基线（如传统优化算法）的运行条件是否与神经网络推理条件一致（精度、迭代终止条件）？

### 4.3 泛化性与最优性
- 跨场景/跨配置/跨信道模型的泛化是否有专门验证，还是只在与训练同分布的测试集上声明？
- "泛化好"的声明是否有分布外（OOD）测试支撑？
- 存在闭式基准/上界时，是否报告与最优解的 gap 数值？（"接近最优"必须给出差多少）

## 5. 指标与报告规范

### 5.1 指标选择
- 指标与问题匹配：可靠性看 BER/BLER/中断概率；容量看频谱效率；能耗看 bits/Joule；用户体感看时延与速率分位数
- 只报均值是否掩盖了尾部分布？（应看 5%/95% 分位数或 CDF/中断曲线）
- 是否只报对自己方法有利的指标，回避不利指标？

### 5.2 单位与坐标轴陷阱
- dB vs 线性值：增益换算是否一致？（dB 域"加 3 dB" = 线性域"翻倍"，两者混用是常见错误）
- per-bit / per-symbol / per-Hz 口径是否统一？
- 对数轴会压缩视觉差异：低 SNR 区看起来接近的曲线可能差数倍
- 功率归一化对象是什么（总功率 vs 每天线功率）？阵元数/RIS 尺寸变化时口径是否守恒？（阵元数翻倍总功率翻倍——"增益"可能只是功率增益）
- 频谱效率的参照带宽是什么？是否把开销比特也计入了有效速率？

### 5.3 性能-复杂度联合报告
- 是否只报性能不报复杂度？
- 复杂度表是否遗漏主导项（大维矩阵分解、迭代算法的实际迭代次数、穷举/搜索类步骤）？
- 增益-代价是否成比例？（2% 增益换 10 倍复杂度是否值得，论文自己是否讨论）

### 5.4 增益表述
- 相对增益与绝对增益并报：低基线上的"提升 25%"可能只有 0.5 dB
- 增益的适用条件是否说明（哪个 SNR 区间/场景/配置下成立）？
- 是否用"接近最优/接近穷举"却不给 gap 数值？
- 是否把标准方法的标准性能包装成自己贡献？（对比对象其实是"什么都不做"）

## 6. 原型与实测评估

- 实验环境是否描述充分（暗室/OTA/室内走廊/现场；距离、遮挡、多径环境）？
- 设备与校准是否说明（频偏校正、相位校准、天线方向图、线缆损耗）？
- 测量重复次数与统计处理（多次测量的均值±方差，还是单次快照）？
- 仿真-实测结果是否对比，gap 是否讨论？
- 原型实现是否与仿真假设一致（同步精度、控制时延、相移精度）？
- 实测场景是否只挑了对信号传播有利的点？

## 7. 红旗速查表

| 红旗 | 常见形态 | 检查动作 |
|------|---------|---------|
| 弱基线陪跑 | 基线未调参/实现粗糙/已过时 | 查基线出处、复现设置、调参程度 |
| 开销不对称 | 导频/训练开销只算自己或只算对方 | 统一开销口径重算对比 |
| 完美假设增益 | 完美 CSI/理想硬件下宣称大增益 | 找鲁棒性/误差模型下的结果 |
| 单点最优展示 | 只报单参数点或最有利 SNR 区间 | 要求全区间参数扫描 |
| 单场景结论 | 单一信道模型/拓扑/频段 | 检查场景列表与覆盖 |
| 无统计支撑 | 单条平滑曲线、无置信区间、重复次数不明 | 查蒙特卡洛次数与 CI |
| 平滑掩盖噪声 | 过度平滑、离群点消失 | 要原始数据/种子/多次运行 |
| 复杂度隐匿 | 复杂度表缺主导项、无实测时延 | 逐项核算（含求逆/迭代/搜索） |
| 相对增益放大 | 大百分比、小绝对值 | 要求并报绝对增益（dB） |
| 证明式语言 | "证明""显著提升"但无统计检验 | 检查措辞与检验方法 |
| 泛化空口宣称 | "适用于任意场景"但只测了一个 | 查 OOD/跨场景验证 |
| 泄漏式评测 | 测试集参与调参、快照不隔离 | 查数据划分协议 |

## 8. 评估输出建议

对通信论文做批判性评估时，建议按以下顺序过清单（与缺陷的影响力排序一致）：

1. **先看系统模型与假设声明** —— 理想化假设、口径定义决定结论适用范围
2. **再看基线与对比设置** —— 公平性决定"增益"是否成立
3. **然后看仿真/实验设置** —— 随机性、扫描、参数决定结果可信度
4. **最后看结论措辞** —— 证据强度与声明强度是否成比例
