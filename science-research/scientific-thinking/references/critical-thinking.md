# 科研批判性思维

## 概述

批判性思维是系统评估科研严谨性的过程：评估方法学、实验/仿真设计、统计有效性、偏倚与混杂、证据质量。本技能的参考体系已按无线通信/工程仿真研究本地化——通信研究特有的评估点（基线公平性、仿真设置、信道模型、ML 方法陷阱、指标规范）见 `wireless-eval.md`，通用方法学框架见本文件。

## 何时使用本技能

- 评估研究方法学与实验/仿真设计
- 评估统计有效性与证据质量
- 识别研究中的偏倚与混杂
- 审查科学论断与结论
- 做系统综述或文献证据梳理
- 对论文提供批判性分析

## 评估模块

### 1. 方法学批判

评估研究方法学的严谨性、有效性与潜在缺陷。

**适用场景：** 审阅论文、评估实验/仿真设计、评估研究方案、规划新研究。

**评估框架：**

1. **研究设计评估**
   - 设计是否与研究问题匹配？
   - 设计能否支撑所宣称的归因（因果/增益来源）？
   - 对比设置是否恰当且充分（基线、消融）？
   - 理论分析、仿真、原型实测的组合是否合理？

2. **效度分析**
   - **内部效度：** 增益/效应真的来自所提机制吗？
     - 基线是否公平（同信道、同开销、同调参努力）？
     - 混杂因素是否受控（实现差异、超参差异、计算预算差异）？
     - 场景/配置的选择偏倚是否排除？
     - 数据的丢弃/排除规则是否对称合理？
   - **外部效度：** 结果能泛化吗？
     - 场景、频段、配置的覆盖是否充分？
     - 仿真假设是否限制实际适用范围（完美 CSI、理想硬件）？
     - 仿真结论是否被过度外推到实测/真实部署？
   - **构念效度：** 指标度量的是宣称的东西吗？
     - 是否用代理指标（特定 SNR 点、特定场景吞吐）代表整体性能？
     - 操作化定义是否清晰？
   - **统计结论效度：** 统计推断可靠吗？
     - 仿真重复次数/误码事件数是否充足？
     - 是否报告置信区间/误差棒？
     - 检验方法是否恰当？

3. **控制与公平性（工程语境的"对照"）**
   - 基线是否为 SOTA 或有代表性的方法，而非刻意挑选的弱基线？
   - 消融实验是否分离出每个组件的贡献？
   - 对比口径是否一致：相同的信道模型、导频/训练开销、天线配置、复杂度计量口径？
   - 基线是否调参到位，还是用默认参数陪跑？

4. **测量质量**
   - 指标是否成熟、与问题匹配（BER vs BLER vs 吞吐量 vs 频谱效率 vs 能效）？
   - 测量协议是否标准化、可复现？
   - 是否用多个指标三角验证，而非只报有利指标？

**参考：** 全流程设计检查单见 `experimental-design.md`；通信特有关切见 `wireless-eval.md`。

### 2. 偏倚检测

识别并评估可能扭曲结论的偏倚来源。

**系统性偏倚审查：**

1. **研究者认知偏倚**
   - **确认偏倚：** 是否只突出支持性结果？
   - **HARKing：** 假设是先验设定，还是看完结果后提出的？
   - **发表偏倚：** 负结果/失败场景是否从文献与论文中消失？
   - **Cherry-picking：** 证据是否被选择性引用？
   - 检查：是否公开代码与完整实验配置、是否预先声明实验计划

2. **选择偏倚**
   - **场景偏倚：** 仿真场景/频段/配置是否只挑有利区间？
   - **数据集偏倚：** 训练/评测数据是否代表目标分布？
   - **幸存者偏倚：** 是否只展示成功的运行/种子？
   - 检查：参数扫描范围、场景列表完整性、基线数量

3. **测量偏倚**
   - **评测者偏倚：** 评测者是否知道哪条结果来自自己的方法？
   - **仪器偏倚：** 测量工具/仿真器本身是否有系统误差？
   - **测试集污染：** 评测数据是否泄漏进训练/调参过程？
   - 检查：盲评、校准、数据划分协议

4. **分析偏倚**
   - **p-hacking：** 是否反复尝试直到出现显著结果？
   - **Outcome switching：** 是否用事后显著的指标替换了预先声明的指标？
   - **选择性报告：** 计划的分析是否都报告了？
   - **子集钓鱼：** 是否无校正地翻找有利子集（子频段、子场景、用户群）？

5. **混杂**
   - 哪些未控变量可能同时影响"所提机制"和"观测结果"？
   - 混杂是否被测量并在分析中控制？
   - 未测混杂能否解释结果？
   - 是否存在合理替代解释（如增益其实来自额外开销而非新机制）？

**参考：** 完整偏倚分类与缓解策略见 `common-biases.md`。

### 3. 统计分析评估

批判性评估统计方法、解读与报告。

**统计审查清单：**

1. **重复次数与统计功效**
   - 仿真独立重复次数/蒙特卡洛样本数是否预先确定且充足？
   - 少次数、少错误事件下的"显著"结果是否提示效应量被夸大？
   - 极低 BER/极小差异的结论是否有足够错误事件支撑？

2. **统计检验**
   - 检验是否匹配数据类型与分布？
   - 检验假设是否检查并满足？
   - 分析是否匹配设计（配对 vs 独立；多次运行能否当独立样本）？

3. **多重比较**
   - 是否测试了多个假设/配置/场景？
   - 是否做了校正（Bonferroni、FDR 等）？
   - 主结果与探索性结果是否区分？
   - 结论会不会只是多重检验的假阳性？

4. **p 值解读**
   - p 值是否被正确解读（原假设为真时出现该数据的概率）？
   - "不显著"是否被错误解读为"无效应"？
   - 统计显著是否被混同于实际重要？
   - 是否只报阈值不报具体值？p 值是否可疑地聚集在 0.05 附近？

5. **效应量与置信区间**
   - 是否与显著性一并报告效应量？
   - 是否给出置信区间以显示精度？
   - 增益是否同时给出绝对值与相对值（低基线上的大百分比可能只有 0.1 dB）？

6. **缺失与丢弃数据**
   - 有多少数据被丢弃？丢弃规则是否预先声明？
   - 丢弃是否对称（各组/各方法同等对待）？
   - 丢弃是否会引入偏倚？

7. **回归与建模**
   - 模型是否过拟合（预测变量过多、无交叉验证）？
   - 是否在数据范围外外推？
   - 多重共线性是否处理？
   - 模型假设是否检查？
   - 训练/测试之间是否存在数据泄露？

8. **常见陷阱**
   - 相关当因果
   - 忽略均值回归
   - 基础比率忽视
   - 得克萨斯神枪手谬误（在噪声中找模式）
   - 辛普森悖论（子群混杂）

**参考：** 42 个统计陷阱详解见 `statistical-pitfalls.md`。

### 4. 证据质量评估

系统评估证据的强度与质量。

1. **工程实证证据等级**
   - 理论分析/闭式解 → 单组仿真 → 多独立组复现的仿真 → 硬件原型/实测 → 现网试验/标准化采纳
   - **重要：** 等级高 ≠ 质量高。设计糟糕的实测可能弱于设计严谨的大规模仿真。

2. **等级内的质量**
   - 偏倚风险、方法严谨性、透明度与报告完整性、利益冲突

3. **证据收敛性**
   - **更强：** 多独立复现、不同方法学（理论/仿真/原型）收敛、机理与经验一致
   - **更弱：** 单一研究或研究组、结果互相矛盾、存在明显选择/发表偏倚、无复现尝试

4. **情境因素**
   - 理论合理性、与既有知识的一致性、参数-性能关系的合理性（如增益随 SNR 单调）

**参考：** 证据等级与质量评估详见 `evidence-hierarchy.md`。

### 5. 逻辑谬误识别

点名并解释科学论证中的逻辑错误。

**常见谬误类别：**

1. **因果类** —— 事后归因、相关当因果、反向因果、单因谬误
2. **概括类** —— 草率概括、轶事证据、cherry-picking、生态学谬误
3. **权威与来源类** —— 诉诸权威、人身攻击、起源谬误、诉诸自然
4. **统计类** —— 基础比率忽视、得州神枪手、多重比较、检察官谬误
5. **结构类** —— 虚假两难、移动球门、循环论证、稻草人
6. **科学专属** —— 伽利略赌博（"他们当年也嘲笑伽利略"）、诉诸无知、完美主义谬误、不可证伪

**识别谬误时：**
- 点名具体谬误
- 解释推理为何不成立
- 说明什么样的证据才是有效推断所需的
- 注意：论证谬误不证明结论为假——只说明该论证不支持结论

**参考：** 40 种谬误完整目录见 `logical-fallacies.md`。

### 6. 研究设计指导

为规划严谨的研究提供建设性指导。

1. **研究问题精炼** —— 具体、可回答、可证伪；确认针对真实空白；确认可行性（科学问题的系统凝练流程见 `problem-refinement.md`）
2. **设计选择** —— 问题匹配设计（机理问题→理论+仿真；部署问题→原型/现网）；因子设计与参数扫描
3. **偏倚最小化** —— 场景覆盖与随机化、评测协议标准化、预先声明主指标
4. **重复规划** —— 预定蒙特卡洛次数/独立重复数；随机种子策略
5. **测量策略** —— 成熟指标、多指标三角验证、硬件测量需校准
6. **分析计划** —— 预先指定假设与分析、定主指标、定缺失/异常数据的处理方式
7. **透明与严谨** —— 公开代码/参数/种子、区分验证性与探索性分析、报告所有结果而非有利子集

**参考：** 全流程设计检查单见 `experimental-design.md`；通信特有设置见 `wireless-eval.md`。

### 7. 论断评估

系统评估科学论断的有效性与支持度。

1. **识别论断**
   - 究竟宣称了什么？
   - 因果论断、相关论断还是描述性论断？
   - 强度如何（证明/很可能/提示/可能）？

2. **评估证据**
   - 提供了什么证据？
   - 直接还是间接？
   - 对论断强度是否充分？
   - 替代解释是否排除？

3. **检查逻辑连接**
   - 结论是否从数据推出？
   - 有无逻辑跳跃？
   - 相关数据是否被用来支持因果论断？
   - 局限是否承认？

4. **评估比例性**
   - 置信度是否与证据强度成比例？
   - 限定措辞是否恰当？
   - 局限是否被淡化？
   - 推测是否明确标注？

5. **检查过度泛化**
   - 论断是否超出所研究的样本/场景？
   - 适用条件是否说明？
   - 情境依赖性是否承认？

6. **红旗**
   - 相关研究用因果语言
   - "证明（prove）"或绝对化表述
   - 选择性引用
   - 无视矛盾证据
   - 回避局限
   - 超出数据范围的外推

**给出具体反馈：**
- 引用问题语句
- 说明支持它需要什么证据
- 建议恰当的限定措辞
- 区分数据（发现了什么）与解读（意味着什么）

## 应用指南

### 总体原则

1. **建设性**
   - 先讲优点，再讲问题
   - 给改进建议而非只批评
   - 区分致命缺陷与次要局限
   - 承认一切研究都有局限

2. **具体**
   - 指向具体位置（"表 2 显示……""方法部分第 3 段"）
   - 引用问题语句
   - 给出问题的具体示例
   - 引用被违反的具体原则或标准

3. **成比例**
   - 批评严重度匹配问题重要性
   - 区分主要效度威胁与次要关切
   - 考虑问题是否影响主结论
   - 对自身评估的不确定性保持诚实

4. **标准一致**
   - 所有研究用同一标准
   - 不因不喜欢结论而加严标准
   - 承认自身潜在偏倚
   - 基于方法学而非结果下判断

5. **考虑情境**
   - 承认实际与资源约束
   - 考虑领域惯例（效应量基准、指标口径）
   - 区分探索性与验证性语境
   - 体谅仿真/原型条件的限制

### 反馈结构

1. **总览** —— 评估对象与范围简述
2. **优点** —— 做得好的地方（对可信度和改进都重要）
3. **问题** —— 按严重度组织：
   - 关键问题（威胁主要结论的效度）
   - 重要问题（影响解读但不致命）
   - 次要问题（值得注意但不改变结论）
4. **具体建议** —— 可执行的改进建议
5. **总评** —— 关于证据质量与可得出结论的平衡结论

**术语精确：**
- 点名具体偏倚、谬误与方法学问题
- 引用公认标准与规范
- 引用科学方法论原则
- 准确使用技术术语

### 不确定时

- **承认不确定：** "这可能是 X 或 Y；还需要 Z 信息"
- **问澄清问题：** "是否做了 [某设置]？这影响解读。"
- **给条件化评估：** "如果做了 X，则 Y 成立；如果没做，则 Z 是问题"
- **说明什么信息能消除不确定**

## 牢记

**科研批判性思维是：**
- 用确立的原则做系统评估
- 以改进研究为目标的建设性批评
- 置信度与证据强度成比例
- 对不确定与局限保持透明
- 标准的一致应用
- 承认一切研究都有局限
- 怀疑与开放之间的平衡

**始终区分：**
- 数据（观察到了什么）与解读（意味着什么）
- 相关与因果
- 统计显著与实际重要
- 探索性与验证性结果
- 已知与未知
- 反驳一个论断的证据与支持原假设的证据

**批判性思维的目标：**
1. 准确识别优点与弱点
2. 判定什么结论是被支持的
3. 识别局限与不确定
4. 为后续工作提出改进
5. 推进科学理解
