# 支撑材料汇总合册

把材料文件夹中按序号命名的单个支撑材料（.pdf / .docx）合并为一本汇总 PDF：
**封面（无页码）→ 目录（页码从1起）→ [分类标题页 + 该分类各项材料] × N**，除封面外每页右下角有页码（封面不计页码）。

## 材料与目录约定

- 文件名以序号开头：`N-名称.pdf` / `N 名称.pdf` / `N-名称.docx`。按序号找文件用正则 `^N([\s\-（]|$)`（裸前缀会把 1 误配给 10）。
- 名称来源：材料文件夹内的 `材料清单记录表.xlsx`（B列=序号、C列=名称）。名称尾部可能带人工待确认标注（如 `（戴校？）`），写入标题/目录前必须去除。
- 分类定义（默认为本实验区7类，可用参数覆盖）：`1:学科专业建设:1:9, 2:师资队伍:10:17, 3:教学平台:18:29, 4:科研平台:30:42, 5:教学成果:43:46, 6:科研成果:47:50, 7:人才培养:51:54`。

## 标准流程（三个脚本按序执行）

所有脚本支持 `--folder`（材料目录，默认 `D:\workspace\claude-code\docx\合并版`）。脚本在技能目录 `scripts/` 下。

### 1) 批量 docx→PDF
```bash
python <skills>/scripts/conv_docx.py --folder <材料目录>
```
- 增量模式：跳过已存在的 PDF。**docx 更新后必须先删除 `_pdf/` 里对应旧 PDF**（或整体清空重转），否则沿用旧转换。
- 自动跳过清单类文件（成果清单分类结果2新 / 材料清单记录表 / ~$ 临时文件）。

### 2) 首页标题（缺“序号N：名称”的文件）
```bash
python <skills>/scripts/add_item_titles.py --folder <材料目录> [--items 11,20,49]
```
- 自动检测：PDF 首页文本 / docx 正文含 `序号N：` 视为已有；纯扫描件无文本层视为缺失。
- PDF：pdftoppm 渲染首页 → 检测顶部留白 → 留白够直接写入 / 不足则原内容等比缩小让出标题带 → **新首页整页替换**（规避 /Rotate 旋转与 pypdf 合并方向陷阱）。首页变为图像页（丢失文本层，佐证可接受）。
- DOCX：正文开头插入左对齐黑体加粗标题段。
- 留白不足的页面原标题条曾覆盖内容顶部——**必须先从原始来源恢复干净文件再叠加**（来源映射见 references/pitfalls.md 第 9、22 条）。

### 3) 封面 / 目录 / 分类标题页 / 页码戳
```bash
python <skills>/scripts/make_front_matter.py --folder <材料目录>
```
- 产出 `_cover.pdf`、`_toc.pdf`（两遍法回填真实页码）、`_dividers.pdf`（每分类1页，黑体40pt加粗，水平+垂直居中）、`_stamp.pdf`（页脚 PAGE 域右对齐）、`pages.json`。
- 页码规则：封面无页码不盖戳；目录页从1起；每个分类占1页标题页计入页码。

### 4) 装配 + 自检
```bash
python <skills>/scripts/assemble.py --folder <材料目录>
```
- 合并 + 右下角页码 + 自动校验（悬空引用 / 逐页页码 / 旋转页），异常时退出码1。

## 常见后续操作

- **更新了某个 word**：删除 `_pdf/` 中对应 PDF → 重跑步骤1、3、4。
- **删除某页**（如“情况说明”页）：Word 文件按内容块定位删除 XML 块；PDF 用 pypdf 去掉对应页。之后重跑步骤3、4。
- **文件名/标题带人员变动**（如删掉某人）：文件名、正文首行标题、目录条目三处同步改；目录名称在 make_front_matter.py 的 names 覆盖处调整。
- **序号重编**：同步更新记录表（按学院分组重建）与分类清单 docx（删行/改序号单元格、标题计数），再重跑步骤3、4。

## 环境依赖

Windows + 本机 Word（win32com）、Python 包 `pypdf` / `PyMuPDF(fitz)` / `Pillow` / `openpyxl`、poppler 的 `pdftoppm`、中文字体 `C:/Windows/Fonts/simhei.ttf`。无 LibreOffice（docx→PDF 用 Word COM）。

## 坑速查（详细症状→原因→已验证解法见 references/pitfalls.md，处理前务必通读）

1. 页码戳叠加到读取器页对象 = 全部丢失 → 必须 writer.pages
2. /Rotate 页叠加内容旋转错位 → 烘焙为图像页
3. PIL 标题条合并方向不可控 → PDF 标题条用 pdftoppm 渲染+PIL 画在渲染图上；整页替换
4. Word 页脚域插入后对齐被重置 → 后设右对齐；Footers 须经 Sections(1)
5. 段前距继承（封面两页）；分页符后段前距不生效 → 分类页独立文档+垂直居中
6. Acrobat “数字越界” = 悬空引用 → PyMuPDF garbage=4 clean 重存；坏字体页重建为图像
7. 目录条目页码累加 cur += pp（非+1）；两遍法断言 t2==t1
8. 封面不编页不盖戳；段前距继承要清零
9. 增量转换缓存陷阱：更新 docx 后必须删旧 PDF
10. pdftoppm 输出页号位数不定 → 按前缀 glob
11. 名称标注（戴校？等）写入前必须去除
