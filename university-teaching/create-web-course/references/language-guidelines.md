# Language Guidelines

Guidelines for creating course content in different languages.

## Language Options

### Chinese (中文)

**When to use:** User selects Chinese or course is primarily for Chinese-speaking students.

**Characteristics:**
- All lesson content in Chinese
- Technical terms in English where appropriate (HTTP, REST API, JSON, etc.)
- Code comments remain as in source code
- Use simplified Chinese (简体中文)

### English

**When to use:** User selects English or course is primarily for English-speaking students.

**Characteristics:**
- All lesson content in English
- Technical terms in their standard form
- Code comments remain as in source code



## Technical Terms

### Keep in English

These technical terms should remain in English regardless of course language:

- HTTP, HTTPS, FTP
- REST API, GraphQL
- JSON, XML, HTML, CSS
- SQL, NoSQL
- MVC, DAO, DTO
- Servlet, JSP, JSF
- Spring Boot, Django, Express
- Git, GitHub, GitLab
- IDE (Integrated Development Environment)
- URL, URI, API
- GET, POST, PUT, DELETE
- Database terms: table, row, column, primary key

### Translate to Chinese

These concepts should be translated:

- "Learning Objectives" → "学习目标" or "本课目标"
- "Checkpoint" → "检查点"
- "Tip" → "提示"
- "Design Decisions" → "设计思路"
- "Concept Explanation" → "概念讲解"
- "Code Implementation" → "代码实现"
- "Execution Flow" → "执行流程"
- "Reflection Questions" → "课后思考"

## Code Comments

**Rule:** Code comments in lesson pages should match the source code exactly.
