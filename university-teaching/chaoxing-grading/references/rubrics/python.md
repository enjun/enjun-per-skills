# 评分标准：Python语言程序设计

适用课程：Python语言程序设计。2026-09-12 批改"第1周作业2"时与用户校准形成；其他课程另建文件。

## 总则

- 满分 100 可以打，**评分公平、前后遵循统一标准即可**；最低 80。
- 权重：**实操完成度（截图验证）占比最高、是决定因素；有无文字说明占比较低。**
- 评语：默认不写，评语框 `#comment<workAnswerId>` 留空（用户要求时再写）。

## 档位

| 分数 | 情形 |
|------|------|
| 100 | 全流程完美：所有实操环节（含创建、激活等每一步）均有截图验证 + 文字说明完整且准确 |
| 95 | 实操全部截图验证 + 文字完整；或全流程完整但文字较简略 |
| 93 | 实操基本完整但个别环节缺截图证据（如创建命令未截到）；或实操完整但纯图片无文字 |
| 92 | 实操完整但文字仅一句话/很弱；或部分过程证据不完整 |
| 87-88 | 缺一整组操作、用错工具；或全程只有结果片段无过程 |
| 85 | 整组缺失且无文字，或严重缺证据 |
| 80 | 只有文字没有任何截图（无实操证据） |

## 证据核对清单

对照作业要求逐项核对截图证据，典型编程作业核对清单：创建环境/初始化 → 激活/进入 → 执行核心命令 → 结果查询（如 Location 路径）→ 退出；多组任务核对各组证据是否齐全、Location 是否互不相同、版本差异等隔离证据。
